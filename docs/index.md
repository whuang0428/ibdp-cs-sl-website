# Welcome

This website is designed for **IBDP Computer Science SL** students.

It follows our school teaching order:

1. **B1 Computational Thinking**
2. **B2 Programming**
3. **B3 Object-Oriented Programming**
4. **A3 Databases**
5. **A1 Computer Fundamentals**
6. **A2 Networks**
7. **A4 Machine Learning**
8. **HL Programming Extension**
9. **Social Engineering Awareness**
10. **Exam Practice / IA Support / Glossary**

::: tip How to use this website
Students should read the lesson page first, then try the guided practice, then check the hidden answer. Teachers can use the same pages for direct teaching, homework, revision, and exam practice.
:::

## Main Course Modules

| Module | Main Focus | Start |
|---|---|---|
| B1 Computational Thinking | Decomposition, abstraction, algorithms, flowcharts, trace tables | [Start B1](/b1-computational-thinking/) |
| B2 Programming | Variables, data types, selection, loops, arrays, searching, sorting, testing | [Start B2](/b2-programming/) |
| B3 OOP | Classes, objects, constructors, encapsulation, UML, multiple classes | [Start B3](/b3-oop/) |
| A3 Databases | Tables, keys, relationships, SQL, normalization, security, transactions | [Start A3](/a3-databases/) |
| A1 Computer Fundamentals | Hardware, CPU, memory, storage, data representation, OS, control systems | [Start A1](/a1-computer-fundamentals/) |
| A2 Networks | LAN/WAN, devices, TCP/IP, packets, DNS, security, VPN, NAT | [Start A2](/a2-networks/) |
| A4 Machine Learning | Features, labels, supervised/unsupervised learning, evaluation, ethics | [Start A4](/a4-machine-learning/) |

## Recommended Student Routine

```text
Read lesson page
→ copy key terms

→ check hidden answer
```

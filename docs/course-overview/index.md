# Course Overview

## What this course is about

IBDP Computer Science SL helps you understand how computer systems work and how computational solutions are designed.

In this course, you will study:

- computer systems
- networks
- databases
- machine learning
- computational thinking
- programming
- object-oriented programming
- the internal assessment computational solution

## Official syllabus structure

The official SL syllabus is organized into two themes.

### Theme A: Concepts of computer science

- [A1 Computer fundamentals](../a1-computer-fundamentals/)
- [A2 Networks](../a2-networks/)
- [A3 Databases](../a3-databases/)
- [A4 Machine learning](../a4-machine-learning/)

### Theme B: Computational thinking and problem-solving

- [B1 Computational thinking](../b1-computational-thinking/)
- [B2 Programming](../b2-programming/)
- [B3 Object-oriented programming](../b3-oop/)

## Assessment connection

- Paper 1: mainly Theme A concepts of computer science, with scenario-based written explanations.
- Paper 2: mainly Theme B computational thinking and problem-solving, with programming / pseudocode application.
- IA: computational solution project where you plan, develop, test, document, and evaluate your own solution.

# Paper 1 Overview

## 1. Page Purpose

This page explains how to prepare for **IBDP Computer Science SL Paper 1** using an exam-practice mindset.

Students should use this page to understand:

```text
what Paper 1 tests
how the paper is structured
how Section A and Section B feel different
how command terms affect answer style
how many details are expected for different mark values
how to approach short questions and longer case-study questions
how to manage time
how to self-mark and improve answers
```

Paper 1 is not only a memory test.  
It checks whether students can apply computer science ideas to realistic systems and scenarios.

## How to use this page

This page is long because it combines Paper 1 overview, exam strategy, common traps, and practice sets. Use it in stages:

1. Read the overview sections first to understand what Paper 1 tests.
2. Use [Paper 1 Case Study Answering Skills](./case-study-answering-skills) for a focused annotation workflow, evidence grid, original worked scenario, and case-linked practice.
3. Review [Command Terms](./command-terms) before writing longer answers.
4. Use [Mark Scheme Skills](./mark-scheme-skills) to improve point, expansion, and scenario-link wording.
5. Return to this page for timing strategy, topic traps, and Paper 1 practice sets.

```text
hardware and system concepts

database design and SQL
```

Students need to turn topic knowledge into mark-scheme style answers.


## 7. Command Term Strategy

| Command Term | What It Means in Paper 1 | Answer Strategy |
|---|---|---|
| State | give one clear answer | short and direct |
| Identify | name the correct item | no long explanation needed |
| List | give several items | separate points |
| Define | give exact meaning | precise technical definition |
| Outline | give brief point with some detail | point + small expansion |
| Describe | give features or process | clear details, not just labels |
| Explain | give reason/how/effect | point + because/how |
| Justify | support a choice | reason linked to scenario |
| Construct | build a correct answer | table/query/design/algorithm |
| Discuss | balanced consideration | for and against / multiple perspectives |
| Evaluate | judge strengths and weaknesses | reasoned judgement |
| To what extent | evaluate degree of success | balanced argument + conclusion |

## 8. Mark Value Strategy

| Marks | Expected Answer Depth |
|---:|---|
| 1 | one correct fact, term, value, or item |
| 2 | two short points OR one point with expansion |
| 3 | three points OR one/two developed points |
| 4 | usually two developed points |
| 5 | several points with scenario link |
| 6 | structured explanation with examples/context |
| 12 | balanced extended response with analysis and conclusion |

### Example

Question:

```text
Outline one benefit of using fiber-optic cable instead of twisted-pair cable. [2]
```

Weak answer:

```text
It is faster.
```

Stronger answer:

```text
Fiber-optic cable can provide higher bandwidth than twisted-pair cable, allowing more data to be transmitted across the hospital network at the same time.
```

This gives:

```text
point = higher bandwidth
expansion/scenario = more data across hospital network
```

## 11. The Case Study Mindset

For case-study questions, students should not write generic textbook answers only.

### Weak Answer

```text
A firewall is useful because it is secure.
```

### Stronger Case-study Answer

```text
A firewall can filter incoming and outgoing network traffic to reduce unauthorized access to TaylorMade Healthcare's internal systems. This is important because hospital patient records are sensitive and a breach could disrupt clinical services.
```

### Case Study Formula

```text
Technical point
→ explanation
→ case-study link
→ possible impact
```

For a complete worked method, use [Paper 1 Case Study Answering Skills](./case-study-answering-skills). It separates case-study reading, evidence selection, short-response development, extended-response planning, and self-marking.

## 12. Paper 1 Timing Strategy

For a 50-mark paper in 75 minutes:

```text
75 minutes / 50 marks = about 1.5 minutes per mark
```

### Suggested Timing

| Part | Time |
|---|---:|
| Quick scan | 2 minutes |
| Section A shorter questions | 35-40 minutes |
| Section B shorter parts | 10-15 minutes |
| Section B extended response | 15-18 minutes |
| Review | 3-5 minutes |

### Practical Rule

```text
1 mark ≈ 1.5 minutes
4 marks ≈ 6 minutes
12 marks ≈ 18 minutes
```

Do not spend 8 minutes on a 2-mark question.

## 13. Answer Planning for 12-mark Questions

A 12-mark question usually needs more than a list.

### Suggested Structure

```text
short introduction / judgement
point 1 with explanation and scenario link
point 2 with explanation and scenario link
point 3 with limitation or opposing view
point 4 with cost/practical/ethical issue
reasoned conclusion
```

### Example Structure

Question type:

```text
To what extent can institutions prevent and respond to cybersecurity attacks?
```

Possible answer structure:

```text
1. They can reduce risk using prevention measures.
2. They can respond using backups, incident response, and recovery planning.
3. However, they cannot fully prevent all attacks because attackers adapt and humans make mistakes.
4. Strong cyber resilience needs investment, training, monitoring, and external support.
5. Conclusion: they can reduce likelihood and impact, but cannot guarantee complete prevention.
```

## 14. 12-mark Answer Quality Levels

### Weak Answer

```text
mostly list
little technical vocabulary
no case-study link

```

### Medium Answer

```text
some relevant points

basic conclusion
```

### Strong Answer

```text
detailed technical understanding
multiple developed points
clear case-study links
balanced analysis

```

### Strong Closing Sentence

```text
Overall, the hospital can reduce the likelihood and impact of cyberattacks through layered security and response planning, but it cannot completely eliminate risk because threats change, staff may make mistakes, and resilience requires ongoing investment.
```

## 15. Common Paper 1 Mistakes

| Mistake | Why It Loses Marks | Better Approach |
|---|---|---|
| writing vague answers | no mark-worthy detail | use technical terms |
| ignoring command term | wrong answer depth | underline command term |
| no scenario link | generic answer | mention organization/data/users |
| repeating same point | does not gain new marks | make separate points |
| writing too much for 1 mark | wastes time | answer directly |
| one sentence for 6 marks | not enough depth | use developed points |
| confusing similar terms | wrong concept | revise comparison tables |
| poor SQL syntax | query not valid | check SELECT/FROM/WHERE |
| incomplete truth table | missing rows/outputs | list all input combinations |
| no conclusion for evaluate | weak extended response | give supported judgement |

## 17. SQL in Paper 1

Paper 1 may include SQL construction.

### Basic Pattern

```sql
SELECT field1, field2
FROM tableName
WHERE condition
ORDER BY field ASC;
```

### DISTINCT

Use `DISTINCT` when the question says:

```text
only appear once
unique
no duplicates
```

Example:

```sql
SELECT DISTINCT PatientName
FROM VISITS
WHERE Treatment LIKE '%therapy%';
```

### Common SQL Checklist

```text
SELECT correct fields
FROM correct table/view
WHERE correct condition
quotes around text values
LIKE used for partial match
DISTINCT used if duplicates must be removed
ORDER BY used if sorting requested
semicolon optional depending on mark scheme, but good habit
```

### Question 2 [2 marks]

Outline the function of an accumulator.

<details>
<summary>Mark Scheme Style Answer</summary>

An accumulator is a register in the CPU used to store intermediate results of arithmetic or logic operations. It may hold results produced by the ALU before they are used in later operations or stored in memory.

</details>

### Question 2 [3 marks]

Describe how atomicity manages transactions across multiple nodes.

<details>
<summary>Mark Scheme Style Answer</summary>

Atomicity ensures that a transaction is treated as one complete unit. Across multiple nodes, either all required updates are completed successfully on all relevant nodes, or the transaction is rolled back so no partial update remains.

</details>

---

### Question 3 [3 marks]

<details>
<summary>Mark Scheme Style Answer</summary>

A spatial database can store location-based data such as addresses or coordinates. This allows the hospital or laboratory to map virus cases, analyse geographic clusters, and identify outbreak patterns by location.

</details>

## 29. Practice Set E: Section B Style

### Question 1 [4 marks]

Outline two strategies a hospital could use to maintain security when employees use their own devices.

<details>
<summary>Mark Scheme Style Answer</summary>

One strategy is multi-factor authentication, requiring employees to provide more than one form of verification before accessing hospital systems. This reduces the risk of unauthorized access if a password is stolen. Another strategy is mobile device management, which can enforce encryption, screen locks, updates, and remote wipe on devices that access hospital data.

</details>

---

### Question 2 [4 marks]

Outline two advantages of a BYOD approach compared with the hospital providing devices.

<details>
<summary>Mark Scheme Style Answer</summary>

One advantage is reduced hardware cost because the hospital does not need to buy as many devices for employees. Another advantage is user familiarity because employees may already know how to use their own devices, reducing training time and possibly improving productivity.

</details>

---

### Question 3 [12 marks]

To what extent can institutions like a hospital prevent and respond to cybersecurity attacks?

<details>
<summary>Mark Scheme Style Answer</summary>

Institutions can reduce the likelihood of cybersecurity attacks by using layered security controls such as firewalls, anti-malware, patching, access control, encryption, multi-factor authentication, and staff training. These controls make it harder for attackers to gain access and reduce the chance that phishing or malware will succeed.

They can also improve their response by preparing backups, incident response plans, failover systems, monitoring, logging, and disaster recovery procedures. For a hospital, this is important because attacks may affect patient records, appointments, medical systems, and patient safety. Good response planning can reduce downtime and support recovery after an incident.

However, institutions cannot fully prevent all cybersecurity attacks. Attackers continually change techniques, staff may make mistakes, zero-day vulnerabilities may exist, and strong security requires ongoing investment. Some measures may also be expensive or difficult to manage, especially when many systems and personal devices are involved.

Overall, institutions can significantly reduce risk and improve resilience, but they cannot guarantee complete prevention. The strongest approach is to combine prevention, detection, response, recovery, staff training, and regular review.

</details>

# Command Terms

## 1. Why Command Terms Matter

Command terms tell students what kind of answer is expected. A student may know the content but lose marks if they answer the wrong command.

## 2. Common Command Terms

| Command Term | Meaning | Student Action |
|---|---|---|
| State | Give a short answer | One clear fact |
| Identify | Name or recognize | Pick from scenario |
| Define | Give meaning | Use precise wording |
| Describe | Give characteristics or steps | Say what happens |
| Explain | Give reason or how/why | Add cause and effect |
| Compare | Give similarities and/or differences | Use both sides |
| Discuss | Give balanced points | Advantages and limitations |
| Evaluate | Judge with reasons | Make a reasoned conclusion |
| Construct | Create or draw | Produce diagram/code/table |
| Trace | Follow step by step | Show values changing |

## 3. Answer Depth by Command

### State / Identify

Usually short.

```text
A primary key uniquely identifies each record in a table.
```

### Describe

Give main features or steps.

```text
Packet switching splits data into packets. Each packet has a header and payload. Packets are routed through the network and reassembled at the destination.
```

### Explain

Give reason, cause, or consequence.

```text
Encryption protects data because it converts plaintext into ciphertext using a key. If data is intercepted, it cannot easily be read without the correct key.
```

### Compare

Mention both sides.

```text
A LAN covers a small geographical area and is usually managed by one organization. A WAN covers a larger geographical area and often uses third-party infrastructure.
```

### Evaluate

Give strengths, weaknesses, and judgement.

```text
Machine learning may help detect high-risk patients earlier by learning patterns from large datasets. However, it needs representative data and may make false negatives. It should be used with human oversight.
```

## 4. Common Mistakes

| Mistake | Example | Better |
|---|---|---|
| Explaining when asked to state | Too long and unfocused | Give direct definition |
| Stating when asked to explain | Only writes term | Add how/why |
| Comparing only one side | Only describes LAN | Describe LAN and WAN |
| Evaluating without judgement | Lists points only | Add final balanced judgement |
| Ignoring scenario | Generic answer | Use the scenario nouns |

## 5. Practice

### Question 1

Command term: **State**  
State one function of an operating system.

<details>
<summary>Answer</summary>

It manages memory used by running programs.

</details>

### Question 2

Command term: **Explain**  
Explain why a queue is suitable for print jobs.

<details>
<summary>Answer</summary>

A queue is suitable because it uses FIFO, meaning the first item added is the first item removed. Print jobs should usually be processed in the order they arrive, so the first submitted job should print first.

</details>

### Question 3

Command term: **Evaluate**  
Evaluate the use of cloud storage for school work.

<details>
<summary>Answer</summary>

Cloud storage allows students to access files from different devices and supports backup and sharing. However, it depends on internet access and raises privacy or provider security concerns. It is useful for school work if accounts are protected and sensitive data is handled carefully.

</details>

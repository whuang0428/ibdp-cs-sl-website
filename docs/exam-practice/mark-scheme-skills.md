# Mark Scheme Skills

## 1. What Mark Schemes Reward

Mark schemes usually reward:

- correct technical terms
- clear explanation
- scenario application
- correct process order
- comparison between two sides
- advantage and limitation
- valid example

## 2. Mark Scheme Writing Formula

### Definition Question

```text
Term + precise meaning
```

Example:

```text
A foreign key is a field in one table that refers to the primary key in another table.
```

### Explanation Question

```text
Concept + how it works + why it matters + scenario link
```

Example:

```text
A VPN creates an encrypted connection over a public network. This protects data sent between a remote worker and the company network because intercepted data is harder to read. It is useful when staff work from home.
```

### Comparison Question

```text
Point of comparison + side A + side B
```

Example:

```text
A LAN covers a small area such as a school building, while a WAN covers a large area such as different cities.
```

### Scenario Recommendation

```text
Choice + reason + scenario link + limitation
```

Example:

```text
An SSD is suitable for a student laptop because it has fast read/write speeds and no moving parts, which helps startup speed and durability. However, it may cost more than an HDD for the same capacity.
```

## 3. How to Match Marks

| Marks | Expected Depth |
|---:|---|
| 1 | One correct point |
| 2 | Two points or one developed point |
| 3 | Definition plus explanation/example |
| 4 | Two developed points |
| 6 | Several linked points, usually with scenario |
| 8+ | Balanced discussion or longer structured answer |

## 4. Weak vs Strong Answers

### Question

Explain why a database is suitable for a hospital.

Weak answer:

```text
Because it stores data.
```

Strong answer:

```text
A database stores related patient data in an organized structure. Doctors can search and update records quickly. Access rights can restrict sensitive medical records to authorized staff. Backups can also help recover data if records are lost or corrupted.
```

## 6. Practice

Rewrite the weak answers.

### Question 1

Explain why a firewall is useful.

Weak answer:

```text
It makes the network safe.
```

<details>
<summary>Improved Answer</summary>

A firewall filters incoming and outgoing network traffic based on security rules. It can block unauthorized or suspicious traffic from reaching the school network. This helps reduce the risk of attacks, although it does not stop all threats such as phishing.

</details>

### Question 2

Explain encapsulation.

Weak answer:

```text
It hides data.
```

<details>
<summary>Improved Answer</summary>

Encapsulation bundles data and methods inside a class and controls access to the data. Attributes are often made private, and public methods are used to read or change them. This protects data because methods can validate values before updating attributes.

</details>

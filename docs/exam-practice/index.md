# Exam Practice

## Section Overview

This section supports IBDP Computer Science SL exam preparation.

It is designed for classroom review, homework, quick quizzes, and independent revision. The focus is not only remembering knowledge points, but also learning how to write answers in a mark scheme-friendly way.

## Pages

| Page | Focus |
|---|---|
| Paper 1 Overview | SL exam structure and preparation habits |
| Command Terms | How to understand question wording |
| Mark Scheme Skills | How to write answers that match marks |
| B1 Practice | Computational thinking questions |
| B2 and B3 Practice | Programming and OOP questions |
| A1 and A2 Practice | Computer fundamentals and networks |
| A3 and A4 Practice | Databases and machine learning |
| Mini Mock Exam Bank | Mixed short exam papers |

## How to Use This Section

1. Review the topic page first.
2. Attempt the questions without looking at answers.
3. Open the hidden answer only after writing your response.
4. Compare your answer with the mark scheme style answer.
5. Highlight missing keywords.
6. Rewrite your answer in a better exam style.

::: tip Student Reminder
For explanation questions, do not only name a term. Explain how it works and connect it to the scenario.
:::

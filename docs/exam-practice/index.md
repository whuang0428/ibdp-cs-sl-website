# Exam Practice

## Section Overview

This section is used for exam-style practice. Questions should be original or school-created, not copied directly from copyrighted official materials.

## Practice Structure

Each practice page should include:

1. topic name
2. question
3. command term
4. marks
5. student answer space
6. mark scheme style answer
7. common mistakes
8. examiner-style comments

## Question Types

| Type | Examples |
|---|---|
| Short Answer | State, identify, outline, describe, explain |
| Algorithm | Trace table, pseudocode, flowchart |
| Programming | Complete code, identify error, write algorithm |
| Database | SQL, keys, relationships, normalization |
| Network | Packet switching, DNS, TCP/IP, security |
| Computer Fundamentals | CPU, memory, logic gates, conversions |
| Machine Learning | Data cleaning, model evaluation, ethics |

## Command Terms

| Command Term | What Students Should Do |
|---|---|
| State | Give a brief answer, often one word or phrase |
| Identify | Pick out or name something |
| Outline | Give a brief description with key point |
| Describe | Give details about what something is or does |
| Explain | Give reasons, causes, or consequences |
| Construct | Create something such as a diagram, table, or query |
| Discuss | Present different points or considerations |

## Mark Scheme Style

A good answer should:

- use correct technical vocabulary
- answer the exact command term
- link the answer to the scenario
- give enough detail for the marks available
- avoid vague statements

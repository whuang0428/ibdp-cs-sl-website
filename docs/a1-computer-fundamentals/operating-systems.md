# Operating Systems

## 1. Lesson Goals

By the end of this lesson, students should be able to:

- define operating system
- explain the main functions of an OS
- distinguish system software and application software
- explain memory, processor, file, device, and user management
- apply OS functions to real scenarios
- write exam-style explanations of OS roles

## 3. Key Terms

| English Term | 中文解释 | Exam-style meaning |
|---|---|---|
| Operating system | 操作系统 | System software that manages hardware and software resources |
| System software | 系统软件 | Software that manages or supports the computer system |
| Application software | 应用软件 | Software used to perform user tasks |
| User interface | 用户界面 | Allows users to interact with the system |
| Memory management | 内存管理 | Allocates and manages RAM |
| Processor scheduling | 处理器调度 | Decides which process gets CPU time |
| File management | 文件管理 | Organizes files and directories |
| Device driver | 设备驱动 | Software that allows OS to communicate with hardware |

### English Explanation

An **operating system** is system software that manages computer hardware and software resources.

It sits between the user, application software, and hardware. Common functions include:

- user interface
- memory management
- processor scheduling
- file management
- device management
- security and access control
- error handling

Do not only say the OS “makes the computer work”. Exam answers should state specific functions and roles.

## 5. Real-life Example

### Example: Opening a document

| OS Function | Example |
|---|---|
| File management | finds the document on storage |
| Memory management | loads the app and file into RAM |
| Processor scheduling | gives CPU time to the app |
| Device management | handles keyboard, mouse, screen |
| User interface | allows user to click and type |

---

## 6. OS Function Pattern

```text
User/Application request → OS manages resources → hardware performs task → result returned to user/application
```

---

## 7. Technical Example

### Function table

| Function | Role |
|---|---|
| User interface | interaction with user |
| Memory management | allocates RAM |
| Processor management | shares CPU time |
| File management | organizes data on storage |
| Device management | controls peripherals using drivers |
| Security | manages users and permissions |

---

## 8. Explanation of the Example

The OS coordinates many resources at once. For example, while a video call runs, the OS manages camera, microphone, network, memory, CPU scheduling, and display output.

## 9. Step-by-step Process / Trace

| Step | Action | OS Function |
|---|---|---|
| 1 | User clicks app | user interface |
| 2 | App loaded | memory management |
| 3 | App runs | processor scheduling |
| 4 | File opened | file management |
| 5 | Output shown | device management |

## 10. Common Mistakes

| Mistake | Why it is a problem | Better habit |
|---|---|---|
| Saying OS is hardware | OS is software | Call it system software |
| Only mentioning user interface | OS has many resource management functions | Include memory/CPU/files/devices/security |
| Confusing app and OS | They have different roles | Application performs user task; OS manages resources |
| Ignoring device drivers | Hardware communication matters | Mention drivers for peripherals |
| Using vague wording | Marks require functions | Name function and describe role |

## 13. Exam-style Questions

### Question 1 [4 marks]

Outline two functions of an operating system.

<details><summary>Mark Scheme Style Answer</summary>

Memory management allocates RAM to running programs. File management organizes files and directories on storage. Processor scheduling allocates CPU time to processes. Device management controls peripherals using drivers.

</details>

### Question 2 [3 marks]

Explain why an OS is needed when using a printer.

<details><summary>Mark Scheme Style Answer</summary>

The OS manages communication between the application and printer, often using a device driver. It sends print jobs to the printer and may manage a print queue.

</details>

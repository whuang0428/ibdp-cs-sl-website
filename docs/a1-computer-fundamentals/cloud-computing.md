# Cloud Computing

## 1. Lesson Goals

By the end of this lesson, students should be able to:

- define cloud computing
- distinguish SaaS, PaaS, and IaaS
- explain advantages and disadvantages of cloud computing
- explain scalability and availability
- apply cloud service models to scenarios
- discuss security and privacy concerns

## 3. Key Terms

| English Term | 中文解释 | Exam-style meaning |
|---|---|---|
| Cloud computing | 云计算 | Using remote servers over a network to store, manage, or process data |
| SaaS | 软件即服务 | Ready-made software delivered over the internet |
| PaaS | 平台即服务 | Platform for developing and deploying applications |
| IaaS | 基础设施即服务 | Virtualized computing infrastructure such as servers and storage |
| Scalability | 可扩展性 | Ability to increase or decrease resources as needed |

| Subscription | 订阅 | Payment model based on ongoing service use |

### English Explanation

**Cloud computing** means using computing resources on remote servers over a network, such as storage, software, platforms, or virtual servers.

Common service models:

- SaaS: ready-made online software, such as online documents or email
- PaaS: a platform for developing and deploying applications
- IaaS: rented virtual servers, storage, and network infrastructure

Advantages include scalability, remote access, and reduced local hardware maintenance. Disadvantages include network dependency, long-term costs, privacy/security risks, and dependence on the provider.

## 5. Real-life Example

### Example: School using cloud services

| Need | Cloud Model | Example |
|---|---|---|
| Online documents | SaaS | students edit documents online |
| Build a school app | PaaS | developers deploy app on platform |
| Host virtual servers | IaaS | school rents server infrastructure |

---

## 6. Cloud Model Pattern

```text
SaaS → use ready-made software
PaaS → develop and deploy applications
IaaS → rent infrastructure such as servers/storage
```

---

## 7. Technical Example

### Scenario matching

| Scenario | Best model | Reason |
|---|---|---|
| Teacher uses online email | SaaS | ready-made software |
| Developer deploys app | PaaS | platform supports development |
| Company rents virtual machines | IaaS | infrastructure is rented |

---

## 8. Explanation of the Example

The three models differ mainly in how much the provider manages and how much control the user has. SaaS gives least technical control but is easiest to use. IaaS gives more infrastructure control but requires more management.

## 10. Common Mistakes

| Mistake | Why it is a problem | Better habit |
|---|---|---|
| Saying cloud means data is in the sky | Cloud uses remote servers | Mention remote data centres/servers |
| Confusing SaaS and PaaS | They serve different users | SaaS is ready software; PaaS is development platform |
| Only listing advantages | Cloud has risks too | Include disadvantages when asked |
| Ignoring internet dependency | Cloud usually needs network access | Mention connectivity |
| Assuming cloud is always cheaper | Long-term subscription costs can be high | Discuss cost in context |

## 11. Guided Practice

### Practice 1

A user edits documents online. Which model is this?

<details><summary>Suggested Answer</summary>

SaaS, because the user is using ready-made software delivered over the internet.

</details>

### Practice 2

Give one risk of cloud storage.

<details><summary>Suggested Answer</summary>

It depends on internet access and may create privacy or security concerns if data is stored by a third-party provider.

</details>

## 13. Exam-style Questions

### Question 1 [3 marks]

Distinguish between SaaS, PaaS, and IaaS.

<details><summary>Mark Scheme Style Answer</summary>

SaaS provides ready-made software over the internet. PaaS provides a platform for developing and deploying applications. IaaS provides virtualized infrastructure such as servers and storage.

</details>

### Question 2 [4 marks]

Explain two advantages of cloud computing for a small business.

<details><summary>Mark Scheme Style Answer</summary>

Cloud computing can reduce the need to buy and maintain local servers. It can also scale resources up or down as demand changes. Staff can access data and services remotely, and backups or availability may be managed by the provider.

</details>

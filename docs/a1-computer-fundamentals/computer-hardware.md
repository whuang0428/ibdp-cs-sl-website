# Computer Hardware

## 1. Lesson Goals

By the end of this lesson, students should be able to:

- define computer hardware
- classify hardware into input, output, processing, memory, storage, and communication devices
- explain the role of common hardware components
- distinguish internal and external hardware
- explain how hardware works with software
- identify suitable hardware for different scenarios
- explain why hardware choice affects performance and usability
- avoid common misconceptions about hardware
- answer exam-style questions about computer hardware

## Start here: match each component to its job

Computer hardware is the physical equipment in a computer system. Learn it by following the data: an **input device** captures data, the **CPU** processes instructions, **primary memory** holds current data and instructions, **secondary storage** keeps data long term, and an **output device** presents the result.

In scenario questions, name the component, state its role, and explain why that role suits the user or system.

## Core checklist

After studying this page, you should be able to:

- classify hardware as input, output, processing, memory, storage, or communication equipment
- distinguish internal hardware, external hardware, and peripherals
- explain how the CPU, RAM, storage, and input/output devices work together
- choose suitable hardware for a stated scenario and justify the choice
- distinguish hardware from software

## 5. Hardware Classification Overview

| Hardware Type | Purpose | Examples |
|---|---|---|
| Input hardware | enters data | keyboard, mouse, scanner, microphone, camera, sensors |
| Output hardware | presents results | monitor, printer, speaker, projector, actuator |
| Processing hardware | processes instructions/data | CPU, GPU |
| Memory hardware | temporarily holds active data/instructions | RAM, cache, ROM |
| Storage hardware | stores data long term | SSD, HDD, USB drive, memory card |
| Communication hardware | sends/receives data | network interface card, Wi-Fi adapter, router, modem |

### Key Exam Idea

A device is classified by its role in the system.

Example:

```text
touchscreen = input and output
```

because it displays information and also receives touch input.

## 6. Internal and External Hardware

## 6.1 Internal Hardware

Internal hardware is usually inside the computer case or device.

Examples:

```text
CPU
RAM
motherboard
SSD
HDD
GPU
power supply
cooling fan
network card
```

### Example

In a desktop computer, the CPU is attached to the motherboard.  
RAM slots are also on the motherboard.  
Storage drives connect to the motherboard.

## 6.2 External Hardware

External hardware is connected from outside the main device.

Examples:

```text
keyboard
mouse
monitor
printer
scanner
webcam
external hard drive
speaker
projector
```

### Peripheral

A peripheral is usually an external device connected to a computer.

Examples:

```text
printer
scanner
keyboard
mouse
external storage
```

::: tip Common Phrase
Internal hardware is inside the main device. External hardware or peripherals are connected from outside.
:::

## 7. Input Hardware

Input hardware allows data to enter the computer system.

| Device | Data Entered | Example Use |
|---|---|---|
| Keyboard | text and commands | typing code |
| Mouse | pointer movement and clicks | selecting icons |
| Touchscreen | touch position | phone/tablet control |
| Microphone | sound | voice recording |
| Camera | images/video | video call |
| Scanner | document image | digitizing paper |
| Barcode reader | barcode data | shop checkout |
| Sensor | physical measurement | temperature, light, pressure |

Sensors are important in control and embedded systems.

Examples:

```text
temperature sensor
light sensor
motion sensor
pressure sensor

```

A sensor converts a physical condition into data the system can process.

## 8. Output Hardware

Output hardware presents results from a computer system.

| Device | Output Produced | Example Use |
|---|---|---|
| Monitor | visual display | showing desktop |
| Printer | paper output | printing report |
| Speaker | sound | playing audio |
| Projector | large visual display | classroom presentation |

| Actuator | physical action | moving a robot arm |
| Vibration motor | haptic feedback | phone vibration |

An actuator is an output device that causes physical action.

Examples:

```text

```

This is especially important in embedded and control systems.

## 9. Processing Hardware

Processing hardware carries out instructions and processes data.

### CPU

The CPU is the main processor.

It:

```text
fetches instructions
decodes instructions
executes instructions
performs calculations
controls data movement
coordinates other components
```

CPU details will be covered in later pages.

### GPU

The GPU is specialized for graphics and many parallel calculations.

It is useful for:

```text
rendering graphics
gaming
video editing
machine learning tasks
scientific simulations
```

### CPU vs GPU Preview

| CPU | GPU |
|---|---|
| general-purpose processor | specialized for many parallel operations |
| strong for sequential control tasks | strong for graphics/parallel tasks |
| runs operating system and program logic | helps render images/video and parallel workloads |

---

## 10. Memory Hardware

Memory hardware holds data and instructions used by the CPU.

### RAM

RAM is temporary working memory.

It stores:

```text
currently running programs
open files
temporary data
data needed soon by CPU
```

RAM is usually volatile, meaning data is lost when power is turned off.

### ROM

ROM is non-volatile memory that stores important startup or firmware instructions.

### Cache

Cache is small, very fast memory close to the CPU.

It stores frequently or recently used data/instructions to speed up processing.

### Memory Preview Table

| Type | Volatile? | Main Use |
|---|---|---|
| RAM | Usually yes | active programs and data |
| ROM | No | firmware/startup instructions |
| Cache | Usually yes | very fast access for CPU |

---

## 11. Storage Hardware

Storage hardware saves data long term.

Examples:

```text
SSD
HDD
USB flash drive
memory card
external hard drive
optical disc
```

### SSD

An SSD has no moving parts and is usually fast.

Used in:

```text
laptops
desktops
servers
game consoles
```

### HDD

An HDD uses spinning magnetic disks.

It is often cheaper per GB but slower than SSD.

### USB Drive / Memory Card

Used for portable storage.

### Storage vs Memory

| Storage | Memory |
|---|---|
| long-term | temporary working area |
| non-volatile | RAM is volatile |
| larger capacity | faster access |
| example: SSD | example: RAM |

| Port / Connector | Common Use |

## 15. Device Drivers Preview

A device driver is software, not hardware.

But it is connected to hardware because it allows the operating system to communicate with a device.

Example:

```text
printer hardware + printer driver software = printer can work correctly
```

### Why Mention Drivers Here?

Because students may think plugging in hardware is always enough.  
Often, software is needed to control hardware.

---

## 16. Hardware and Software Working Together

Hardware performs physical operations.  
Software gives instructions.

### Example: Webcam Video Call

| Component | Role |
|---|---|
| Webcam | captures video input |
| Microphone | captures audio input |
| CPU | processes video/audio data |
| RAM | holds active call data |
| Network adapter | sends/receives data |
| Screen | displays video output |
| Speaker | plays audio output |
| Video call app | application software |
| Operating system | manages devices and resources |

### Key Idea

No single part does everything.  
A real system uses many hardware and software components together.

## 20. Choosing Suitable Hardware

Hardware should be chosen based on the task.

| Scenario | Suitable Hardware Choice | Reason |
|---|---|---|
| Video editing | powerful CPU/GPU, large RAM, fast SSD | handles large media files |
| School typing laptop | keyboard, enough RAM, SSD, good battery | everyday productivity |
| Gaming PC | strong GPU, CPU, RAM, cooling | graphics and real-time performance |
| Server | reliable storage, large RAM, network hardware | many users/data requests |
| Digital art | graphics tablet, colour-accurate monitor | drawing input and visual output |
| Embedded traffic light | sensors, controller, actuators/lights | dedicated control task |

## 21. Hardware and Performance

Hardware affects system performance.

| Hardware Factor | Possible Effect |
|---|---|
| Faster CPU | instructions processed more quickly |
| More RAM | more programs/data can be active |
| Larger cache | CPU may access common data faster |
| SSD instead of HDD | faster file loading and boot time |
| Better GPU | improved graphics/video performance |
| Faster network adapter | better data transfer speed |
| Better cooling | reduces overheating and throttling |

### Important

More expensive hardware is not always necessary.  
The best hardware depends on the task.

## 22. Common Mistakes

| Mistake | Why it is wrong | Better understanding |
|---|---|---|
| Hardware means only CPU | CPU is one hardware component | Hardware includes all physical components |
| Monitor is the computer | Monitor is output hardware | Computer system has many parts |
| RAM is storage | RAM is temporary memory | Storage saves long term |
| Software is hardware because it is “in the computer” | Software is instructions/data | Hardware is physical |
| Printer driver is hardware | Driver is software | Printer is hardware |
| Touchscreen is only output | It also receives touch input | Touchscreen is input and output |
| CPU and GPU are the same | They have different strengths | CPU general, GPU graphics/parallel |
| More storage means faster computer | Capacity is not speed | SSD speed, RAM, CPU also matter |
| Sensors are output devices | Sensors detect input | Actuators create output/action |
| All external devices are output devices | Some are input or storage | Classify by function |

## 25. Exam-style Questions

### Question 1 [4 marks]

Define hardware and give two examples.

<details>
<summary>Mark Scheme Style Answer</summary>

Hardware refers to the physical components of a computer system. Examples include the CPU, RAM, keyboard, monitor, SSD, printer, and motherboard.

</details>

---

### Question 2 [5 marks]

Distinguish between input and output hardware using examples.

<details>
<summary>Mark Scheme Style Answer</summary>

Input hardware is used to enter data into a computer system, such as a keyboard entering text or a microphone entering sound. Output hardware is used to present results from a computer system, such as a monitor displaying images or a printer producing a paper document.

</details>

---

### Question 3 [6 marks]

A student says that RAM and SSD are the same because both store data. Explain why this is incorrect.

<details>
<summary>Mark Scheme Style Answer</summary>

RAM and SSD both hold data, but they have different roles. RAM is temporary working memory used while programs are running and is usually volatile, so its contents are lost when power is off. An SSD is secondary storage used to save files and programs long term and is non-volatile. RAM is generally faster, while SSD usually has larger long-term capacity.

</details>

---

### Question 4 [6 marks]

Explain how hardware and software work together when printing a document.

<details>
<summary>Mark Scheme Style Answer</summary>

The user uses application software such as a word processor to request printing. The operating system manages the print job, and the printer driver translates the request into instructions the printer can understand. Hardware such as the CPU processes the request, the network or USB connection transfers data, and the printer produces the paper output.

</details>

---

### Question 5 [6 marks]

A smart thermostat measures room temperature and turns heating on or off. Identify suitable input, processing, and output hardware.

<details>
<summary>Mark Scheme Style Answer</summary>

A temperature sensor is input hardware because it detects the room temperature. A processor or microcontroller is processing hardware because it decides whether heating is needed. An actuator, relay, or heating control is output hardware because it turns the heating system on or off. A display may also be output hardware because it shows the temperature.

</details>

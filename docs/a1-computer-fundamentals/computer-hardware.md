# Computer Hardware

## 1. Lesson Goals

By the end of this lesson, students should be able to:

- define **hardware** and **software**
- identify input, output, processing, storage, and communication devices
- explain how hardware components work together
- classify devices in real-world scenarios
- compare hardware choices for different users
- write exam-style answers using precise technical vocabulary

## 3. Key Terms

| English Term | 中文解释 | Exam-style meaning |
|---|---|---|
| Hardware | 硬件 | The physical components of a computer system |
| Software | 软件 | Programs and data used by a computer system |
| Input device | 输入设备 | Hardware used to enter data into a computer |
| Output device | 输出设备 | Hardware used to present information from a computer |
| Storage device | 存储设备 | Hardware used to store data and programs |
| Processor / CPU | 处理器 | Hardware that executes instructions |
| Peripheral | 外设 | External device connected to a computer system |

### English Explanation

**Hardware** means the physical components of a computer system, such as CPU, RAM, keyboard, monitor, and SSD.

**Software** means programs and data, such as an operating system, browser, word processor, or game.

A complete computer system usually includes:

- input: entering data, such as keyboard, mouse, microphone
- processing: processing data, such as CPU
- storage: saving data, such as SSD or HDD
- output: displaying or presenting results, such as monitor, speaker, printer
- communication: connecting to other devices or networks, such as network card or router

In exams, avoid only saying “a computer has hardware”. Better answers state a specific device and its role.

## 5. Real-life Example

### Example: Laptop used for online learning

| Function | Hardware Example | Role |
|---|---|---|
| Input | keyboard, webcam, microphone | enter text, video, and sound |
| Processing | CPU | executes instructions for apps |
| Storage | SSD | stores files and programs |
| Output | screen, speakers | displays video and plays sound |
| Communication | Wi-Fi adapter | connects to the network |

::: info Scenario Link
A laptop needs several types of hardware working together. A webcam alone does not make online learning possible; the CPU, memory, storage, output devices, and network connection are also needed.
:::

## 6. System Structure Pattern

```text
Input data → Processing → Storage if needed → Output result
```

For many scenario questions, first identify the role of each device in this pattern.

## 7. Technical Example

### Classifying devices

| Device | Category | Reason |
|---|---|---|
| Keyboard | Input | Enters text |
| Monitor | Output | Displays information |
| SSD | Storage | Saves data permanently |
| CPU | Processing | Executes instructions |
| Network card | Communication | Connects to network |

---

## 8. Explanation of the Example

Hardware should be classified by what it does in the system. Some devices can have more than one role. For example, a touchscreen is both input and output because it displays information and accepts touch input.

---

## 9. Step-by-step Process / Trace

| Step | Action |
|---|---|
| 1 | User types a web address using keyboard |
| 2 | CPU processes the browser request |
| 3 | Network adapter sends request to network |
| 4 | Data returns from the web server |
| 5 | Screen displays the webpage |
| 6 | Cache or storage may save temporary data |

## 10. Common Mistakes

| Mistake | Why it is a problem | Better habit |
|---|---|---|
| Calling software hardware | Software is not physical | Check whether it can be physically touched |
| Classifying every device as input | Devices have different roles | Use input/output/processing/storage categories |
| Ignoring CPU role | Processing is essential | Explain that CPU executes instructions |
| Using vague examples | Marks need technical detail | Name the device and its function |
| Forgetting communication devices | Modern systems often need networks | Include network hardware when scenario needs it |

## 11. Guided Practice

### Practice 1

Identify one input, output, storage, and processing device in a desktop computer.

<details>
<summary>Suggested Answer</summary>

Input: keyboard. Output: monitor. Storage: SSD or HDD. Processing: CPU.

</details>

### Practice 2

Why is a touchscreen both input and output?

<details>
<summary>Suggested Answer</summary>

It displays information to the user, so it is output. It also accepts touch actions from the user, so it is input.

</details>

## 13. Exam-style Questions

### Question 1 [2 marks]

State what is meant by hardware.

<details>
<summary>Mark Scheme Style Answer</summary>

Hardware is the physical components of a computer system that can be touched, such as CPU, keyboard, monitor, or storage device.

</details>

### Question 2 [4 marks]

A student uses a laptop for online lessons. Identify two hardware components and explain their roles.

<details>
<summary>Mark Scheme Style Answer</summary>

The webcam is an input device because it captures video of the student. The screen is an output device because it displays the teacher, slides, and learning materials. The CPU processes instructions for the video call software. The Wi-Fi adapter allows the laptop to connect to the network.

</details>

## 14. Classroom Activity

### Activity: Hardware Sorting

**Time:** 10-15 minutes  
Students sort cards into input, output, processing, storage, and communication. Then they justify any device that can belong to more than one category.

::: tip Exit Ticket
Write one sentence explaining the difference between hardware and software.
:::

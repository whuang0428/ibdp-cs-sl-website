# Course Roadmap

## Teaching Order

| Order | Unit | Main Focus |
|---|---|---|
| 1 | B1 Computational Thinking | Problem-solving process, algorithms, flowcharts, trace tables |
| 2 | B2 Programming | Variables, selection, loops, arrays, searching, sorting, files |
| 3 | B3 Object-Oriented Programming | Classes, objects, methods, constructors, encapsulation |
| 4 | A3 Databases | Tables, keys, relationships, normalization, SQL |
| 5 | A1 Computer Fundamentals | CPU, memory, binary, logic gates, operating systems |
| 6 | A2 Networks | LAN, WAN, TCP/IP, DNS, packet switching, security |
| 7 | Machine Learning | ML concepts, training/testing data, classification, ethics |

## Extension Content

| Extension | Purpose |
|---|---|
| HL Programming | Improve students' coding ability beyond SL |
| Social Engineering Awareness | Teach defensive cybersecurity awareness only |

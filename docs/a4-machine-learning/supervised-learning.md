# Supervised Learning

## 1. Lesson Goals

By the end of this lesson, students should be able to:

- define supervised learning
- explain the role of labelled data
- distinguish classification and regression in supervised learning
- describe training and prediction steps
- identify supervised learning scenarios
- explain limitations and risks

## 3. Key Terms

| English Term | 中文解释 | Exam-style meaning |
|---|---|---|
| Supervised learning | 监督学习 | Machine learning using labelled data to learn input-output relationships |
| Labelled data | 有标签数据 | Training examples with known correct outputs |
| Classification | 分类 | Predicting a category |
| Regression | 回归 | Predicting a numerical value |
| Training data | 训练数据 | Data used to teach the model |
| Prediction | 预测 | Output generated by the model for new data |
| Ground truth | 真实标签 | The correct known answer used for training or evaluation |

### English Explanation

**Supervised learning** trains a model using labelled data. Each training example has features and a correct label. The model learns the relationship between inputs and outputs, then makes predictions for new data. Common tasks include classification, which predicts a category, and regression, which predicts a number.

## 5. Real-life Example

### Example: Email Spam Classifier

| Features | Label |
|---|---|
| sender, links, keywords, message length | spam / not spam |

The model is trained on emails where the correct label is already known. After training, it predicts whether a new email is spam.

---

## 6. Core Pattern

```text
Labelled data → train model → model learns feature-label relationship → new data → prediction
```

---

## 7. Technical Example

| Task | Output type | Example |
|---|---|---|
| Classification | category | spam or not spam |
| Regression | number | predicted house price |

---

## 8. Explanation of the Example

In supervised learning, the training data acts like examples with answers. The model uses known labels to learn how features relate to output.

---

## 9. Step-by-step Process / Trace

| Step | Action | Example |
|---|---|---|
| 1 | Collect labelled data | emails marked spam/not spam |
| 2 | Extract features | links, keywords |
| 3 | Train model | learn patterns |
| 4 | Test model | use unseen labelled emails |
| 5 | Predict new case | classify new email |

---

## 10. Common Mistakes

| Mistake | Why it is a problem | Better habit |
|---|---|---|
| Saying supervised means human watches every prediction | Supervised means labelled training data | Use labelled examples definition |
| Confusing classification and regression | Output types differ | Category vs number |
| Ignoring label quality | Incorrect labels harm training | Mention accurate labels |
| Calling clustering supervised | Clustering usually uses unlabelled data | Use unsupervised for clustering |
| Assuming perfect predictions | Models can make mistakes | Discuss testing and evaluation |

## 11. Guided Practice

### Practice 1

Is predicting house price classification or regression?

<details><summary>Suggested Answer</summary>

Regression, because the output is a numerical value.

</details>

### Practice 2

Why does supervised learning need labels?

<details><summary>Suggested Answer</summary>

Labels provide the correct output for each example, allowing the model to learn the relationship between features and target output.

</details>

## 13. Exam-style Questions

### Question 1 [2 marks]

State what is meant by supervised learning.

<details><summary>Mark Scheme Style Answer</summary>

Supervised learning trains a model using labelled data, where each example has known input features and a correct output label.

</details>

### Question 2 [4 marks]

A hospital trains a model to predict whether a patient is high risk. Explain how supervised learning could be used.

<details><summary>Mark Scheme Style Answer</summary>

The hospital could use labelled patient records where the features include age, symptoms, test results, and medical history, and the label indicates high risk or not high risk. The model is trained to learn patterns between the features and labels. It can then predict the risk category for new patients, but it should be tested and checked for bias.

</details>

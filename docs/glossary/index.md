# Glossary

## Section Overview

This glossary collects important IBDP Computer Science terms. Students should learn both the English term and the Chinese meaning.

## How to Use This Glossary

For each term, students should know:

- spelling
- short definition
- where it appears in the course
- one example
- one exam-style phrase

## Core Terms

| Term | Chinese Meaning | Short Definition |
|---|---|---|
| Algorithm | 算法 | A step-by-step method for solving a problem |
| Abstraction | 抽象 | Removing unnecessary details and focusing on important features |
| Decomposition | 分解 | Breaking a problem into smaller parts |
| Variable | 变量 | A named storage location for data |
| Data Type | 数据类型 | The kind of data a value can store |
| Selection | 选择结构 | Code that makes decisions using conditions |
| Iteration | 迭代 / 循环 | Repeating instructions |
| Array | 数组 | A data structure that stores multiple values |
| Class | 类 | A blueprint for creating objects |
| Object | 对象 | An instance of a class |
| Attribute | 属性 | Data stored inside an object |
| Method | 方法 | A behaviour or action of an object |
| Encapsulation | 封装 | Keeping data protected inside a class |
| Primary Key | 主键 | A field that uniquely identifies a record |
| Foreign Key | 外键 | A field that links to a primary key in another table |
| Query | 查询 | A request to retrieve or manipulate database data |
| CPU | 中央处理器 | The main processor that executes instructions |
| ALU | 算术逻辑单元 | CPU component that performs arithmetic and logic operations |
| RAM | 随机存取存储器 | Volatile primary memory |
| ROM | 只读存储器 | Non-volatile memory used for startup instructions |
| LAN | 局域网 | A network over a small geographical area |
| WAN | 广域网 | A network over a large geographical area |
| Router | 路由器 | A device that forwards data between networks |
| Switch | 交换机 | A device that forwards data within a LAN |
| DNS | 域名系统 | Translates domain names into IP addresses |
| Packet | 数据包 | A small unit of data sent across a network |
| Machine Learning | 机器学习 | Systems learning patterns from data |
| Training Data | 训练数据 | Data used to build a machine learning model |
| Testing Data | 测试数据 | Data used to evaluate a model |

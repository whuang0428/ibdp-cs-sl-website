# Command Terms Glossary

## Common Command Terms

| Command Term | 中文理解 | What to Do |
|---|---|---|
| State | 写出 | Give a short direct answer |
| Identify | 识别 | Name the correct item from context |
| Define | 定义 | Give the meaning of a term |
| Describe | 描述 | Say what happens or list features |
| Explain | 解释 | Give how or why with cause/effect |
| Compare | 比较 | Give similarities and/or differences |
| Discuss | 讨论 | Give balanced points |
| Evaluate | 评价 | Judge with evidence and conclusion |
| Construct | 构建 | Produce a diagram, table, algorithm, or code |
| Trace | 跟踪 | Follow step by step and show changes |

## Common Answer Starters

| Command | Useful Sentence Starter |
|---|---|
| Define | “A ___ is ...” |
| State | “One function is ...” |
| Describe | “First..., then..., finally...” |
| Explain | “This is because...” |
| Compare | “A ___ ..., whereas a ___ ...” |
| Discuss | “One advantage is..., however...” |
| Evaluate | “Overall, this is suitable because..., but...” |
| Trace | “The value changes from... to...” |

## Example Transformations

### Weak

```text
A firewall is safe.
```

### Strong

```text
A firewall filters incoming and outgoing network traffic based on rules. This can block unauthorized traffic and help protect the school network.
```

### Weak

```text
ML uses data.
```

### Strong

```text
Machine learning trains a model using data so it can learn patterns and make predictions on new data.
```

## Student Reminder

For 4+ mark questions, one sentence is usually not enough. Use technical term + explanation + scenario link.

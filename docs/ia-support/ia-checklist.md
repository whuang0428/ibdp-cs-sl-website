# IA Checklist

## 1. Topic Checklist

- [ ] I have a real client or clear target user.
- [ ] The problem is specific.
- [ ] The project is not too simple.
- [ ] The project is not too large.
- [ ] The solution requires programming or computational thinking.
- [ ] I can test whether the solution works.

## 2. Analysis Checklist

- [ ] I described the client/user.
- [ ] I explained the current problem.
- [ ] I explained why the current method is limited.
- [ ] I listed functional requirements.
- [ ] I listed non-functional requirements.
- [ ] I identified data needed by the system.
- [ ] I considered constraints.

## 3. Design Checklist

- [ ] I wrote clear success criteria.
- [ ] Each success criterion is measurable.
- [ ] I included interface design or wireframes.
- [ ] I included algorithm design.
- [ ] I included data design.
- [ ] I included validation design.
- [ ] I explained diagrams in words.

## 4. Development Checklist

- [ ] I showed important code sections.
- [ ] I explained code logic, not only pasted code.
- [ ] I documented problems and fixes.
- [ ] I showed validation and error handling.
- [ ] I used appropriate data structures.
- [ ] I kept development evidence.

## 5. Testing Checklist

- [ ] I tested every success criterion.
- [ ] I included normal test data.
- [ ] I included invalid test data.
- [ ] I included boundary test data where suitable.
- [ ] I recorded expected and actual results.
- [ ] I marked pass/fail honestly.
- [ ] I fixed failed tests or explained limitations.

## 6. Evaluation Checklist

- [ ] I evaluated each success criterion.
- [ ] I used test evidence.
- [ ] I included client/user feedback where possible.
- [ ] I explained limitations.
- [ ] I suggested realistic future improvements.
- [ ] I reflected on what I learned.

## 7. Academic Honesty Checklist

- [ ] I wrote my own code or clearly acknowledged help.
- [ ] I did not copy an online project as my own.
- [ ] I cited external libraries, tutorials, or resources.
- [ ] I can explain every important part of my code.
- [ ] I followed school and IB academic honesty rules.

## 8. Final Student Reminder

A strong IA is not only a working product. It is a well-documented process showing analysis, design, development, testing, evaluation, and reflection.

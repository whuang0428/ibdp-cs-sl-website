# A3 Databases

## Unit Overview

This unit introduces how data can be stored, organized, searched, protected, and recovered using databases.

Students learn the structure of relational databases, how tables are connected, how keys work, how SQL retrieves data, and how database design can reduce redundancy and improve reliability.

## How to Study A3

1. Learn the database vocabulary first.
2. Practise identifying entities, attributes, records, and fields.
3. Practise choosing primary and foreign keys.
4. Practise relationship questions using real scenarios.
5. Practise SQL step by step.
6. Connect security, privacy, and recovery to real systems.

::: tip Course Standard
A3 is very scenario-based. Students should always explain database ideas using the case in the question, such as a school, hospital, shop, library, or banking system.
:::

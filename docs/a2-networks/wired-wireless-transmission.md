## 1. Lesson Goals

By the end of this lesson, students should be able to:

- explain what network transmission means
- distinguish wired and wireless transmission
- identify common wired transmission media
- identify common wireless transmission methods
- explain the role of copper cable, fibre optic cable, Wi-Fi, Bluetooth, and mobile networks
- compare wired and wireless transmission in terms of speed, reliability, mobility, cost, range, interference, and security
- explain bandwidth, latency, interference, and attenuation at a basic level
- choose suitable transmission methods for different scenarios
- explain why networks may use both wired and wireless transmission
- connect transmission methods to LAN, WAN, packet switching, and network security
- avoid common misconceptions about wired and wireless networks
- answer exam-style questions about wired and wireless transmission

Transmission method questions often ask students to choose the most suitable option for a situation.

Students should not only name a method. A strong answer should match the method to the scenario using factors such as speed, distance, reliability, mobility, cost, interference, and security.

## Wired vs wireless decision table

| Scenario factor | Wired may be better when... | Wireless may be better when... |
|---|---|---|
| Speed | high and stable speed is needed | moderate speed is acceptable |
| Mobility | devices stay in one place | users need to move around |
| Reliability | connection must be stable | occasional interference is acceptable |
| Installation | cables can be installed easily | cabling is difficult or expensive |
| Security | physical connection is preferred | encryption and authentication are used |
| Range | long fixed links are needed, especially with fibre | short to medium flexible access is needed |

---

## Scenario answer pattern

Use this order when answering transmission scenario questions:

1. Identify the setting and user needs.
2. Decide whether mobility is important.
3. Consider speed, distance, reliability, interference, cost, and security.
4. Choose a suitable transmission method.
5. Justify the choice using details from the scenario.
6. Mention one limitation if the question asks for evaluation.

### Scenario choice example

For a school computer lab with fixed desktop PCs, wired Ethernet is suitable because the devices do not need mobility and the lab needs stable, low-latency connections. A limitation is that cables must be installed and maintained.

## 5. What Is Network Transmission?

Network transmission means sending data between devices.

Data is represented as signals as it travels.

### Signal Examples

| Transmission Type | Signal |
|---|---|
| copper cable | electrical signals |
| fibre optic cable | light pulses |
| Wi-Fi | radio waves |
| Bluetooth | short-range radio waves |
| mobile network | cellular radio signals |

### Basic Process

```text
data
→ converted into signal
→ signal travels through medium
→ receiver detects signal
→ signal converted back into data
```

### Diagram

```mermaid
flowchart LR
    A[Sender Data] --> B[Signal]
    B --> C[Transmission Medium]
    C --> D[Receiver]
    D --> E[Data Reconstructed]
```

## 6. Wired Transmission

Wired transmission uses physical cables to carry data signals.

Common wired media include:

```text
twisted pair copper cable
coaxial cable
fibre optic cable
```

In many school and office LANs, the most common wired connection is Ethernet over twisted pair copper cable.

### General Advantages

```text
stable connection
high speed
low latency
less wireless interference
more difficult to intercept without physical access
good for fixed devices
```

### General Disadvantages

```text
requires cables
installation can be expensive or messy
less flexible for moving devices
cables can be damaged
limited by cable length and infrastructure
```

## 8. Copper Cable

Copper cables carry data using electrical signals.

### Advantages

```text
widely available
relatively cheap
easy to install for short/local distances
suitable for many LANs
```

### Disadvantages

```text
affected by electromagnetic interference
signal weakens over distance
lower maximum distance than fibre
can be tapped if physically accessed
```

### Twisted Pair

Twisted pair cable twists pairs of wires together to reduce interference.

Common Ethernet cables use twisted pair copper wiring.

## 9. Fibre Optic Cable

Fibre optic cable transmits data as pulses of light through thin glass or plastic fibres.

### Advantages

```text
very high bandwidth
fast over long distances
less affected by electromagnetic interference
more secure against electrical tapping
lower signal loss over distance
useful for backbone and long-distance links
```

### Disadvantages

```text
more expensive to install
requires specialist equipment
can be harder to repair
fragile if bent or damaged badly
```

### Common Uses

```text
internet backbone
connection between buildings
data centres
high-speed ISP links
long-distance WAN connections
school or campus backbone
```

### Fibre optic example

::: tip Exam Phrase
Fibre optic cable uses pulses of light to transmit data and is suitable for high-speed, long-distance communication.
:::

## 16. Wired vs Wireless Core Comparison

| Feature | Wired | Wireless |
|---|---|---|
| Medium | physical cable | radio/electromagnetic waves |
| Mobility | low | high |
| Stability | usually higher | may vary |
| Speed | often higher and more consistent | depends on signal/users/standard |
| Latency | often lower | often higher or less stable |
| Interference | less affected by radio interference | more affected by interference |
| Security | requires physical access to cable, but still needs security | easier to intercept if poorly secured |
| Setup | cabling required | easier for mobile devices |
| Best for | fixed devices, servers, labs | phones, laptops, flexible spaces |

## 17. Bandwidth and Throughput

### Bandwidth

Bandwidth is the maximum data transfer capacity of a connection.

Example:

```text
1 Gbps Ethernet
100 Mbps broadband
```

### Throughput

Throughput is the actual data transfer rate achieved.

It may be lower than bandwidth because of:

```text
interference
congestion
distance
protocol overhead
device limits
server limits
number of users
```

### Example

A Wi-Fi network may advertise high bandwidth, but actual throughput may be lower if many students are connected.

---

## 18. Latency

Latency is the delay in communication.

It affects how quickly a response is received.

### Low-latency Applications

```text
online gaming
video calls
remote control systems
voice calls
live streaming interaction
```

### High Latency Causes Problems

High latency may cause:

```text
lag in games
delay in video calls
slow response in remote desktop
poor real-time control
```

### Wired vs Wireless

Wired connections often have lower and more stable latency.  
Wireless latency can vary due to interference, signal strength, and congestion.

---

## 19. Interference

Interference is unwanted signal disruption.

### Wireless Interference Sources

```text
other Wi-Fi networks
Bluetooth devices
microwaves
walls and metal objects
many users sharing same channel
electrical devices
```

### Wired Interference Sources

Copper cables can be affected by electromagnetic interference from:

```text
power cables
motors
poor shielding
nearby electrical equipment
```

Fibre optic cable is much less affected by electromagnetic interference because it uses light.

---

## 20. Attenuation

Attenuation means signal weakening over distance.

### Examples

```text
Wi-Fi signal becomes weaker far from access point
copper cable signal weakens over long distance
fibre optic signal also weakens but can travel much further
```

### Effects

Attenuation can cause:

```text
lower speed
packet loss
connection drops
more errors
need for repeaters/amplifiers/access points
```

### How to Reduce It

```text
shorter cable runs
better cable quality
repeaters or switches
more access points
fibre for long distances
better antenna/access point placement
```

## 22. Security Comparison

### Wired Security

Wired networks may be more difficult to access remotely because an attacker often needs physical access to a cable or port.

But wired networks still need:

```text
authentication
permissions
firewalls
network monitoring
physical security
port security
```

### Wireless Security

Wireless signals can travel beyond walls, so they need strong protection.

Wireless security methods include:

```text
WPA2/WPA3
strong Wi-Fi password
guest network separation
device authentication
disable weak encryption
network monitoring
```

### Important

Wireless is not automatically unsafe, and wired is not automatically secure.  
Both require proper security controls.

## Common mistakes

Watch for these mistakes in scenario answers:

- saying wireless is always better because it is convenient
- saying wired is always better without considering mobility
- forgetting interference for wireless
- forgetting installation cost for wired networks
- confusing Wi-Fi with the internet
- confusing Bluetooth with Wi-Fi
- choosing fibre optic without explaining distance or speed needs
- giving a method without linking it to the scenario

### Common exam trap

A method name alone is not enough. Link the choice to the scenario, such as fixed devices, required mobility, distance, reliability, interference, cost, or security.

## 31. Common Mistakes

| Mistake | Why it is wrong | Better understanding |
|---|---|---|
| Wireless means no network hardware | Wireless still needs APs, routers, NICs | Only cables are removed for user device |
| Wi-Fi and internet are the same | Wi-Fi connects device to local network | Internet is global network |
| Wired is always faster in every case | Depends on cable, standard, devices | But wired is often more stable |
| Wireless is always insecure | Proper encryption can secure Wi-Fi | Poor configuration is risky |
| Fibre optic uses electricity | Fibre uses light pulses | Copper uses electrical signals |
| Bluetooth is suitable for school-wide LAN | Bluetooth is short range | Wi-Fi/Ethernet are more suitable |
| Bandwidth and latency are the same | Bandwidth is capacity; latency is delay | Both affect performance |
| High bandwidth removes all lag | Latency and packet loss still matter | Especially for games/calls |
| Cable length never matters | Signals weaken over distance | Attenuation matters |
| More access points always improve Wi-Fi | Poor placement can cause interference | Plan coverage and channels |

## 34. Exam-style Questions

### Question 1 [4 marks]

Distinguish between wired and wireless transmission.

<details>
<summary>Mark Scheme Style Answer</summary>

Wired transmission sends data using physical cables such as copper Ethernet cable or fibre optic cable. Wireless transmission sends data using electromagnetic or radio signals such as Wi-Fi, Bluetooth, or mobile networks. Wired connections are often more stable and lower latency, while wireless connections provide mobility and convenience.

</details>

---

### Question 2 [5 marks]

Explain two advantages of fibre optic cable compared with copper cable.

<details>
<summary>Mark Scheme Style Answer</summary>

Fibre optic cable can provide higher bandwidth, allowing large amounts of data to be transmitted quickly. It is also suitable for longer distances because it has lower signal loss than copper. Another advantage is that it is less affected by electromagnetic interference because it uses pulses of light rather than electrical signals.

</details>

---

### Question 3 [6 marks]

A school is designing a network for desktop computer labs and student laptops. Explain why it may use both wired and wireless transmission.

<details>
<summary>Mark Scheme Style Answer</summary>

The school may use wired Ethernet for desktop computer labs because the devices are fixed in place and need stable, fast, low-latency connections. It may use wireless Wi-Fi for student laptops and tablets because these devices need mobility and convenient access in classrooms, libraries, and shared spaces. Using both methods provides reliability for fixed infrastructure and flexibility for portable devices.

</details>

---

### Question 4 [5 marks]

Explain how interference and attenuation can affect wireless communication.

<details>
<summary>Mark Scheme Style Answer</summary>

Interference occurs when unwanted signals disrupt wireless communication, such as other Wi-Fi networks, Bluetooth devices, microwaves, or many devices using the same channel. Attenuation is the weakening of a signal over distance or through obstacles such as walls. These can reduce speed, increase packet loss, raise latency, or cause connection drops.

</details>

---

### Question 5 [6 marks]

A student says, “Wi-Fi and the internet are the same thing.” Explain why this is incorrect.

<details>
<summary>Mark Scheme Style Answer</summary>

This is incorrect because Wi-Fi is a wireless technology used to connect a device to a local network, such as a home or school LAN. The internet is a global network of connected networks. A device may use Wi-Fi to reach a router, and the router then connects to the internet through an ISP. Wi-Fi is only one access method and does not itself mean the internet.

</details>

## 37. One-page Revision Summary

| Point | Summary |
|---|---|
| Transmission | Sending data between devices |
| Wired | Uses physical cables |
| Wireless | Uses radio/electromagnetic signals |
| Ethernet | Common wired LAN connection |
| Copper cable | Electrical signals, common and cheaper |
| Fibre optic | Light pulses, high speed, long distance |
| Wi-Fi | Wireless LAN access |
| Bluetooth | Short-range personal wireless |
| Mobile network | Wide-area cellular access |
| Bandwidth | Maximum transfer capacity |
| Throughput | Actual achieved transfer rate |
| Latency | Delay |
| Interference | Unwanted signal disruption |
| Attenuation | Signal weakening over distance |
| Wired advantage | stable, fast, low latency |
| Wireless advantage | mobile and convenient |
| Exam phrase | Wired transmission uses physical cables, while wireless transmission uses radio/electromagnetic signals; the best choice depends on speed, range, mobility, cost, reliability, and security needs |

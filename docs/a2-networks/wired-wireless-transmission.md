# Wired and Wireless Transmission

## 1. Lesson Goals

By the end of this lesson, students should be able to:

- compare wired and wireless transmission
- identify Ethernet, fibre optic, Wi-Fi, Bluetooth, and cellular
- explain advantages and disadvantages of transmission media
- choose suitable transmission method for scenarios
- discuss interference, security, mobility, cost, and speed
- write exam-style comparison answers

## 3. Key Terms

| English Term | 中文解释 | Exam-style meaning |
|---|---|---|
| Transmission medium | 传输介质 | The path used to carry data signals |
| Wired transmission | 有线传输 | Data transmission using physical cables |
| Wireless transmission | 无线传输 | Data transmission using electromagnetic waves |
| Ethernet | 以太网 | Common wired LAN technology |
| Fibre optic | 光纤 | Cable transmitting data using light |
| Wi-Fi | 无线网络 | Wireless local network technology |
| Bluetooth | 蓝牙 | Short-range wireless communication |
| Cellular | 蜂窝网络 | Mobile network communication such as 4G/5G |

## 4. Concept Explanation

### 中文讲解

数据可以通过 wired 或 wireless 方法传输。

**Wired transmission** 使用 cable，例如 Ethernet copper cable 或 fibre optic cable。通常更稳定、安全性较好、受干扰较少，但移动性差，安装可能麻烦。

### English Explanation

Data can be transmitted using wired or wireless methods.

**Wired transmission** uses cables, such as Ethernet copper cable or fibre optic cable. It is usually more stable, can be more secure, and is less affected by interference, but it has less mobility and may be harder to install.

**Wireless transmission** uses radio waves or other electromagnetic waves, such as Wi-Fi, Bluetooth, and cellular. It supports mobility and flexible installation, but may suffer from interference, limited range, and higher security risks.

The best choice depends on the scenario, such as classroom, hospital, factory, home, or outdoor use.

## 5. Real-life Example

### Example: School network

| Location / Use | Suitable Medium | Reason |
|---|---|---|
| Server room | wired Ethernet/fibre | stable and fast |
| Student laptops | Wi-Fi | mobility in classrooms |
| Wireless mouse | Bluetooth | short-range device connection |
| Remote field trip | cellular | access away from school Wi-Fi |

---

## 6. Transmission Decision Pattern

```text
Need speed/stability/security → wired
Need mobility/flexibility → wireless
Need long distance/high bandwidth backbone → fibre optic
Need short-range personal devices → Bluetooth
```

---

## 7. Technical Example

### Comparison table

| Medium | Strength | Weakness |
|---|---|---|
| Ethernet | stable LAN connection | needs cable |
| Fibre optic | high bandwidth, long distance | installation cost |
| Wi-Fi | mobile and flexible | interference/security risk |
| Bluetooth | low power, short range | limited range/speed |
| Cellular | wide mobile coverage | cost and signal dependence |

---

## 8. Explanation of the Example

A wired connection is not always better. A hospital device that must move between rooms may need wireless connection even if wired is more stable.

## 9. Step-by-step Process / Trace

| Step | Wired example |
|---|---|
| 1 | Device sends electrical/light signal through cable |
| 2 | Switch receives data |
| 3 | Data is forwarded through LAN |

| Step | Wireless example |
|---|---|
| 1 | Device converts data into radio signal |
| 2 | Signal travels through air |
| 3 | Wireless access point receives it |
| 4 | Data enters wired LAN or internet path |

## 10. Common Mistakes

| Mistake | Why it is a problem | Better habit |
|---|---|---|
| Saying wireless has no security | Wireless can be secured but has higher exposure | Mention encryption/authentication |
| Saying wired is always best | Scenario may require mobility | Use scenario needs |
| Confusing Wi-Fi and internet | Wi-Fi connects device to local network; internet is wider network | Separate access method and destination |
| Ignoring interference | Wireless signals can be affected | Mention walls, distance, other signals |
| Ignoring installation cost | Cabling can cost time and money | Compare trade-offs |

## 11. Guided Practice

### Practice 1

Why might fibre optic be used between buildings?

<details><summary>Suggested Answer</summary>

It supports high bandwidth and long-distance transmission, and is less affected by electromagnetic interference.

</details>

### Practice 2

Why might Wi-Fi be better than Ethernet for tablets?

<details><summary>Suggested Answer</summary>

Wi-Fi allows mobility and avoids needing cables, which is useful for portable devices.

</details>

## 13. Exam-style Questions

### Question 1 [4 marks]

Compare wired and wireless transmission.

<details><summary>Mark Scheme Style Answer</summary>

Wired transmission uses physical cables and is often more stable, faster, and less affected by interference. However, it limits mobility and may require installation. Wireless transmission allows mobile devices to connect flexibly, but can be affected by interference, distance, and security risks.

</details>

### Question 2 [3 marks]

Explain why a school may use both Ethernet and Wi-Fi.

<details><summary>Mark Scheme Style Answer</summary>

Ethernet may be used for servers and fixed desktop computers because it is stable and fast. Wi-Fi may be used for student laptops and tablets because they need mobility around classrooms.

</details>

# A2 Networks

::: info Syllabus area
Theme A: Concepts of computer science. A2 Networks helps you understand how devices communicate, how data moves across networks, and how communication can be protected.
:::

## Assessment connection

- Paper 1: tests networking concepts, protocols, transmission, security, and scenario-based explanations.
- Paper 2: may support option questions where network design, web access, or security affects a system.
- IA: helps you justify network, security, access, and deployment choices in a computational solution.

## 1. Module Overview

A2 Networks introduces how computer systems communicate with each other.

In this module, students learn how devices:

```text
connect to networks
share resources
send and receive data
use protocols
access websites
split data into packets
protect communication
use wired and wireless media
connect local networks to the internet
```

A2 is important because almost every modern computer system depends on networking:

```text
websites
cloud storage
online games
school LMS
email
video calls
databases
mobile apps
banking systems
IoT devices
```

The main goal of A2 is not only to memorize terms, but to understand how data travels from one device to another safely and reliably.

---

## 2. Learning Goals

By the end of A2 Networks, students should be able to:

- define computer network
- explain why networks are used
- distinguish LAN and WAN
- explain common network devices and their roles
- distinguish switch, router, modem, access point, NIC, and firewall
- explain client-server and peer-to-peer models
- describe the TCP/IP model and its layers
- explain packet switching
- explain DNS and web access
- compare wired and wireless transmission
- explain common network security threats
- recommend security measures for different scenarios
- explain encryption, VPN, and NAT
- connect networking concepts to school, home, cloud, website, and online game scenarios
- answer exam-style questions using correct technical vocabulary

---

## 3. A2 Learning Path

Recommended learning order:

```text
Overview
→ Network Fundamentals
→ LAN and WAN
→ Network Devices
→ Client-Server and Peer-to-Peer
→ TCP/IP Model
→ Packet Switching
→ DNS and Web Access
→ Wired and Wireless Transmission
→ Network Security
→ Encryption, VPN and NAT
```

This order is intentional.

Students first learn what networks are and why they are used.  
Then they learn network size, network devices, and network models.  
After that, they study layered communication, packet switching, and web access.  
Finally, they compare transmission media and study network security.

## 7. Whole Network Communication Pattern

A useful big-picture pattern is:

```text
Application need
→ protocol rules
→ data split into packets
→ addresses added
→ packets transmitted
→ routers forward packets
→ destination reassembles data
→ application uses the result
```

### Example: Opening a Website

```text
browser needs webpage
→ HTTPS request created
→ TCP/IP prepares data
→ packets are sent through network
→ routers forward packets
→ web server receives request
→ server sends response packets
→ browser receives and displays page
```

## 8. Network Fundamentals Pattern

A network is two or more connected devices that can communicate and share resources.

### Key Ideas

| Concept | Meaning |
|---|---|
| Network | connected devices communicating |
| Node | any device on a network |
| Client | requests service/resource |
| Server | provides service/resource |
| Protocol | communication rules |
| Bandwidth | maximum capacity |
| Throughput | actual achieved transfer rate |
| Latency | delay |

### Exam Phrase

Networks allow devices to communicate and share resources, but they require protocols and security controls.

---

## 9. LAN and WAN Pattern

| Feature | LAN | WAN |
|---|---|---|
| Full name | Local Area Network | Wide Area Network |
| Coverage | small local area | large geographical area |
| Example | school network | internet |
| Ownership | often privately managed | may use ISP/telecom infrastructure |
| Latency | usually lower | often higher |
| Security control | easier locally | harder across external networks |

### Quick Memory

```text
LAN = local
WAN = wide
Internet = global WAN / network of networks
```

---

## 10. Network Devices Pattern

| Device | Main Role |
|---|---|
| NIC | allows device to connect to network |
| Switch | connects devices inside a LAN |
| Router | connects different networks |
| Wireless access point | allows wireless devices to join LAN |
| Modem | connects to ISP service line |
| Firewall | filters traffic based on rules |

### Most Important Distinction

```text
switch = inside LAN
router = between networks
modem = ISP line
access point = Wi-Fi access
firewall = traffic filtering
```

---

## 11. Client-Server and Peer-to-Peer Pattern

| Feature | Client-Server | Peer-to-Peer |
|---|---|---|
| Structure | central server provides services | peers share directly |
| Control | centralized | decentralized |
| Cost | higher server/admin cost | lower initial setup cost |
| Management | easier centrally | harder across devices |
| Security | easier to enforce centrally | each peer must be secured |
| Example | website, school file server | direct file sharing |

### Exam Phrase

Client-server uses central servers to provide services, while peer-to-peer allows devices to share resources directly with each other.

---

## 12. TCP/IP Model Pattern

The TCP/IP model explains layered communication.

| Layer | Main Role | Examples |
|---|---|---|
| Application | network services for applications | HTTP, HTTPS, DNS |
| Transport | communication between applications | TCP, UDP |
| Internet | addressing and routing | IP |
| Network Access | local transmission | Ethernet, Wi-Fi |

### Encapsulation

When sending:

```text
Application data
→ TCP/UDP header
→ IP header
→ frame information
→ signals
```

When receiving, the process happens in reverse.

---

## 13. Packet Switching Pattern

Packet switching sends data by splitting it into packets.

### Packet Contents

```text
header
payload
possibly trailer/check
```

### Header May Include

```text
source address
destination address
sequence number
error checking information
protocol information
```

### Process

```text
data split into packets
→ packets routed independently
→ packets may take different routes
→ destination checks and reorders
→ data reassembled
```

### Exam Phrase

Packet switching divides data into packets that are independently routed and reassembled at the destination.

---

## 14. DNS and Web Access Pattern

When a user opens a webpage:

```text
1. User enters URL.
2. Browser identifies domain name.
3. DNS resolves domain name to IP address.
4. Browser establishes HTTP/HTTPS communication.
5. Request is sent to web server.
6. Server sends response.
7. Data travels as packets.
8. Browser renders webpage.
```

### Key Distinctions

| Term | Meaning |
|---|---|
| URL | full web address |
| Domain name | human-readable server/site name |
| IP address | address used for routing |
| Browser | client |
| Web server | server |
| DNS | resolves name to IP |
| HTTPS | secure web communication |

---

## 15. Wired and Wireless Transmission Pattern

| Feature | Wired | Wireless |
|---|---|---|
| Medium | cable | radio/electromagnetic waves |
| Mobility | low | high |
| Stability | usually higher | may vary |
| Latency | often lower | often less stable |
| Security | physical access harder | signal may extend beyond walls |
| Examples | Ethernet, fibre | Wi-Fi, Bluetooth, mobile |

### Choosing Transmission

Use wired when:

```text
speed, stability, low latency, and fixed devices matter
```

Use wireless when:

```text
mobility, convenience, and flexible access matter
```

## 16. Network Security Pattern

Network security protects:

```text
confidentiality
integrity
availability
```

### Threats

```text
unauthorized access
malware
ransomware
phishing
social engineering
DoS / DDoS
interception
misconfiguration
insider threat
```

### Controls

```text
authentication
authorization
firewalls
encryption
anti-malware
updates
backups
monitoring
user education
network segmentation
secure Wi-Fi
```

### Security Control Types

| Type | Purpose | Example |
|---|---|---|
| Prevention | stop attacks | firewall, MFA |
| Detection | notice attacks | logs, monitoring |
| Recovery | restore after incident | backups |

---

## 17. Encryption, VPN and NAT Pattern

| Concept | Main Purpose | Example |
|---|---|---|
| Encryption | protect data content | HTTPS encrypts login details |
| VPN | create encrypted tunnel | remote access to school network |
| NAT | translate private/public IP addresses | home devices share one public IP |

### Quick Memory

```text
Encryption = protect meaning
VPN = protect path/tunnel
NAT = translate address
```

### Important

```text
NAT is not encryption.
VPN does not make everything safe.
HTTPS does not prove a website is honest.
Encryption does not replace backups.
```

## 21. Common A2 Mistakes Overview

| Mistake | Topic | Fix |
|---|---|---|
| Wi-Fi means internet | Transmission | Wi-Fi connects to LAN; internet is global network |
| WAN means wireless | LAN/WAN | WAN means wide area network |
| Router and switch are same | Network Devices | switch connects LAN devices; router connects networks |
| Modem and router are same | Network Devices | modem connects ISP line; router routes between networks |
| Client means human user | Client-server | client is device/program requesting service |
| Server must be huge machine | Client-server | server is defined by service role |
| TCP and IP do same job | TCP/IP | TCP reliability; IP routing |
| DNS sends webpage | DNS/Web | DNS resolves domain to IP |
| HTTP and HTTPS are same | DNS/Web/Security | HTTPS adds encryption |
| Packet means whole file | Packet Switching | packet is small unit |
| Packets always take same route | Packet Switching | packets may route independently |
| Bandwidth and latency are same | Fundamentals | bandwidth is capacity; latency is delay |
| Encryption and NAT are same | Encryption/NAT | encryption protects content; NAT translates address |
| VPN makes everything safe | VPN | VPN helps but does not stop phishing/malware |
| Firewall stops all attacks | Security | firewall is one layer of security |
| Backup is security only after attack | Security | backup supports recovery/availability |

## 24. Mini Diagnostic Check

### Question 1

What is a computer network?

<details>
<summary>Answer</summary>

A computer network is two or more connected devices that can communicate and share data or resources.

</details>

---

### Question 2

What is the main difference between LAN and WAN?

<details>
<summary>Answer</summary>

A LAN covers a small local area, while a WAN covers a large geographical area and can connect multiple LANs.

</details>

---

### Question 3

What is the difference between a switch and a router?

<details>
<summary>Answer</summary>

A switch connects devices within a LAN.  
A router connects different networks and forwards packets between them.

</details>

---

### Question 4

What does DNS do?

<details>
<summary>Answer</summary>

DNS resolves domain names into IP addresses.

</details>

---

### Question 5

Why are packets given sequence numbers?

<details>
<summary>Answer</summary>

Sequence numbers help the destination put packets back into the correct order.

</details>

---

### Question 6

What is the difference between encryption and NAT?

<details>
<summary>Answer</summary>

Encryption protects data content by making it unreadable without a key.  
NAT translates private and public IP addresses; it does not encrypt data.

</details>

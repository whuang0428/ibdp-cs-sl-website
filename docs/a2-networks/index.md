# A2 Networks

## Unit Overview

This unit introduces how computer systems communicate across networks.

Students learn the purpose of networks, different network types, network hardware, client-server and peer-to-peer models, the TCP/IP model, packet switching, DNS, web access, wired and wireless transmission, network security, encryption, VPNs, and NAT.

A2 is highly scenario-based. Students must be able to explain **why** a technology is suitable for a given organization, school, home, hospital, or business.

## How to Study A2

1. Learn the core vocabulary.
2. Practise explaining processes step by step.
3. Compare technologies using scenario needs.
4. Use examples such as school network, home network, online shopping, hospital database, and cloud service.
5. Practise mark scheme-style answers with technical keywords.

::: tip Course Standard
A2 pages use bilingual concept explanations, technical process diagrams in text, scenario examples, exam-style questions, hidden mark scheme answers, classroom activities, and homework.
:::

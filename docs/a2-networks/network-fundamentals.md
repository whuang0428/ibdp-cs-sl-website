# Network Fundamentals

## 1. Lesson Goals

By the end of this lesson, students should be able to:

- define a **computer network**
- explain why networks are used
- identify common network components
- distinguish communication, resource sharing, and centralized management
- explain advantages and disadvantages of networking
- apply network ideas to school and business scenarios

## 3. Key Terms

| English Term | 中文解释 | Exam-style meaning |
|---|---|---|
| Network | 网络 | A set of connected devices that can communicate and share resources |
| Node | 节点 | A device connected to a network |
| Data transmission | 数据传输 | Sending data from one device to another |
| Bandwidth | 带宽 | The amount of data that can be transmitted per second |
| Latency | 延迟 | Delay before data is received |
| Resource sharing | 资源共享 | Using shared devices or files across a network |
| Protocol | 协议 | A set of rules for communication |

### English Explanation

A **network** is a set of connected devices that can communicate and share resources.

Devices on a network may include computers, servers, printers, phones, routers, switches, and wireless access points.

Main purposes of networks include:

- sharing files and data
- sharing hardware such as printers
- allowing users to access the internet
- supporting communication such as email, web, and video calls
- centralizing user management, permissions, and backups

Networks also have risks, such as security threats, privacy issues, shared failure points, and maintenance cost.

## 5. Real-life Example

### Example: School Network

| Network Use | Example |
|---|---|
| File sharing | students access files from a shared drive |
| Printer sharing | many classrooms use one network printer |
| Internet access | all devices connect through school network |
| User management | accounts and permissions controlled centrally |
| Backup | student work can be backed up to a server |

::: info Scenario Link
A school network is useful because many users need shared access to resources, but it must be protected using accounts, permissions, and security rules.
:::

## 6. Network Structure Pattern

```text
Device / node → network device → transmission medium → other device / server → response returned
```

---

## 7. Technical Example

### Basic network components

| Component | Role |
|---|---|
| Client computer | requests services or resources |
| Server | provides services or resources |
| Switch | connects devices in a LAN |
| Router | connects different networks |
| Transmission medium | carries data, such as cable or wireless signal |

---

## 8. Explanation of the Example

A network is not only the internet. A small classroom with connected computers and a shared printer is also a network. The internet is a very large network of networks.

## 9. Step-by-step Process / Trace

| Step | Action |
|---|---|
| 1 | User opens a file from shared storage |
| 2 | Client sends request across network |
| 3 | Network devices forward the request |
| 4 | Server checks access rights |
| 5 | File data is sent back |
| 6 | Client displays or opens the file |

---

## 10. Common Mistakes

| Mistake | Why it is a problem | Better habit |
|---|---|---|
| Saying network means only the internet | A network can be local or global | Define network as connected devices |
| Only listing advantages | Exam may ask balanced discussion | Include disadvantages when relevant |
| Confusing bandwidth and latency | They measure different things | Bandwidth = capacity, latency = delay |
| Ignoring security | Networks introduce access risks | Mention protection methods |
| Using vague terms like faster | Need scenario detail | Explain what becomes faster or easier |

## 11. Guided Practice

### Practice 1

Give two advantages of a school network.

<details><summary>Suggested Answer</summary>

Students can access shared files, and multiple users can share printers or internet access. User accounts can also be managed centrally.

</details>

### Practice 2

Give one disadvantage of networking computers.

<details><summary>Suggested Answer</summary>

If the network is not secure, unauthorized users may access data. Network failure can also affect many users at once.

</details>

## 13. Exam-style Questions

### Question 1 [2 marks]

State what is meant by a computer network.

<details><summary>Mark Scheme Style Answer</summary>

A computer network is a set of connected devices that can communicate and share data or resources.

</details>

### Question 2 [4 marks]

A school connects classroom computers to a network. Explain two benefits.

<details><summary>Mark Scheme Style Answer</summary>

The school can share resources such as printers and files, reducing duplication of hardware and making files easier to access. User accounts and permissions can be managed centrally, improving administration and security. Internet access can also be provided to all devices through the network.

</details>

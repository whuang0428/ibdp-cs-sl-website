# Assessment Overview

IBDP Computer Science SL assessment is not only one exam paper. You need to prepare for written exam skills, option-style applied questions, and the Internal Assessment project.

This page gives you the big picture before you move into exam practice or IA Support.

## 1. What Assessment Includes

| Assessment part | What it focuses on | How to prepare |
| --------------- | ------------------ | -------------- |
| Paper 1 | Core syllabus knowledge, Theme A and Theme B ideas, technical explanations, and problem-solving | Learn the topic content, practise command terms, and write answers that match the mark scheme style |
| Paper 2 | Option-based and applied computer science questions | Prepare the chosen option separately and practise applying knowledge to longer contexts |
| IA | A computational solution project with documentation, product, video, and appendix | Use IA Support to plan, build, test, and evaluate the project using Criteria A-E |

The exact details of assessment instructions can change by session, so always follow the latest guidance from your teacher and school.

## 2. Paper 1

Paper 1 is mainly about the core course. It checks whether you can explain computer science concepts and solve problems using knowledge from Theme A and Theme B.

You should be ready to:

* define and explain technical terms
* compare methods, systems, or approaches
* apply concepts to small scenarios
* trace algorithms or code
* interpret data, diagrams, pseudocode, or short program fragments
* write answers that match the command term

Paper 1 preparation should not only be memorisation. You need to practise turning knowledge into clear exam answers.

## 3. Paper 2

Paper 2 is an option-based and applied paper. It should be prepared separately from Paper 1 because the style is usually more focused on applying knowledge within a chosen option or context.

You should be ready to:

* understand the option content required by your class
* read longer contexts carefully
* connect technical knowledge to a scenario
* justify choices and trade-offs
* use precise terminology
* practise the specific paper structure your teacher gives you

Do not assume that Paper 1 practice is enough for Paper 2. Paper 2 needs its own preparation route and its own examples.

## 4. IA

The IA is a computational solution project. It is not just a report about technology and it is not just a small coding exercise.

For the IA, you choose a topic within computer science, specify a problem, build a suitable software solution, document the process, demonstrate the product, and evaluate the result.

Use [IA Support](/ia-support/) for the IA route. It is organised around:

* Criterion A: Problem specification
* Criterion B: Planning
* Criterion C: System overview
* Criterion D: Development
* Criterion E: Evaluation

## 6. Common Preparation Mistakes

| Mistake | Why it causes problems | Better approach |
| ------- | ---------------------- | --------------- |
| Only revising definitions | Exams often require application and explanation | Practise using terms in scenario-based answers |
| Treating Paper 2 like extra Paper 1 practice | Paper 2 has its own option focus | Prepare the chosen option separately |
| Starting the IA too late | The IA needs planning, development, testing, and evaluation | Use IA Support early and keep evidence as you build |
| Ignoring command terms | Answers may not match what the question asks for | Practise explain, compare, evaluate, outline, and justify-style responses |
| Writing unsupported claims | Marks usually require clear evidence or reasoning | Link each answer to technical detail or the given scenario |

# Assessment Overview

IBDP Computer Science SL assessment is not only one exam paper. You need to prepare for written exam skills, applied computational thinking, and the Internal Assessment project.

This page gives you the big picture before you move into exam practice or IA Support.

## 1. What Assessment Includes

| Assessment part | SL time | Weighting | What it focuses on |
| --------------- | -------: | --------: | ------------------ |
| Paper 1 | 1 hour 15 minutes | 35% | Theme A concepts of computer science plus questions connected to the externally provided case study |
| Paper 2 | 1 hour 15 minutes | 35% | Theme B computational thinking and problem-solving; programming questions are available in Java and Python |
| IA computational solution | 35 hours | 30% | An individual computational solution to a real-world problem of the student's own choosing |

::: info Official reference
These SL assessment figures were checked on **22 July 2026** against the [IB Computer Science subject brief for first assessment 2027](https://www.ibo.org/globalassets/new-structure/university-admission/pdfs/dp_comp_sci_subjectbrief_en.pdf) and the [IB Computer Science curriculum update](https://www.ibo.org/university-admission/latest-curriculum-updates/computer-science-updates/). Session instructions can still change, so follow the latest guidance from your teacher and school.
:::

## 2. Paper 1

Paper 1 is mainly about Theme A: concepts of computer science. It also includes questions connected to the case study. You need to explain computer science concepts, apply them to realistic systems, and use case-study details as evidence where relevant.

You should be ready to:

* define and explain technical terms
* compare methods, systems, or approaches
* apply concepts to small scenarios
* apply Theme A knowledge to the case-study organisation, systems, problems, and stakeholders
* interpret data, diagrams, or short technical fragments
* write answers that match the command term

Paper 1 preparation should not only be memorisation. You need to practise turning knowledge into clear exam answers.

## 3. Paper 2

Paper 2 should be prepared separately from Paper 1 because it focuses on Theme B: computational thinking and problem-solving. Programming is required for some questions, and equivalent Java and Python versions are provided. Prepare using the language studied by your class.

You should be ready to:

* understand the Paper 2 skills required by your class
* read longer contexts carefully
* trace algorithms, flowcharts, pseudocode, or code carefully
* connect computational thinking ideas to a scenario
* justify choices and trade-offs
* use precise terminology
* practise Java or Python using the language studied by your class
* practise using the latest specimen and session guidance provided by your teacher

Do not assume that Paper 1 practice is enough for Paper 2. Paper 2 needs its own preparation route and applied computational thinking examples.

## 4. IA

The IA is a 35-hour computational solution project worth 30% of the final SL grade. It is not just a report about technology and it is not just a small coding exercise.

For the IA, you choose a topic within computer science, specify a problem, build a suitable software solution, document the process, demonstrate the product, and evaluate the result.

Use [IA Support](/ia-support/) for the IA route. It is organised around:

* Criterion A: Problem specification
* Criterion B: Planning
* Criterion C: System overview
* Criterion D: Development
* Criterion E: Evaluation

The public subject brief confirms the time, weighting, real-world problem, and computational-thinking focus. Detailed submission packaging, word/video limits, criteria instructions, and appendix requirements must be checked against the latest official guidance available through your school.

## 5. Collaborative Sciences Project

The course also includes a **10-hour collaborative sciences project**. It is collaborative practical work completed with students from other science subjects and is separate from the individual IA computational solution.

The project is part of the course practical programme, but it is not listed as a separate assessed component in the SL assessment table. Follow your school's schedule and instructions for the project.

## 7. Common Preparation Mistakes

| Mistake | Why it causes problems | Better approach |
| ------- | ---------------------- | --------------- |
| Only revising definitions | Exams often require application and explanation | Practise using terms in scenario-based answers |
| Treating Paper 2 like extra Paper 1 practice | Paper 2 has its own applied problem-solving focus | Practise Theme B, programming / pseudocode, and scenario-based questions separately |
| Starting the IA too late | The IA needs planning, development, testing, and evaluation | Use IA Support early and keep evidence as you build |
| Ignoring command terms | Answers may not match what the question asks for | Practise explain, compare, evaluate, outline, and justify-style responses |
| Writing unsupported claims | Marks usually require clear evidence or reasoning | Link each answer to technical detail or the given scenario |

# Quality Control

## Section Overview

This section is used after all course content pages have been created.

The goal is to move the website from:

```text
Pages exist and links work
```

to:

```text
Pages are ready for real classroom teaching and student revision
```

## Pages

| Page | Purpose |
|---|---|
| Teaching Quality Audit | Main checklist for checking every page |
| Module Audit Table | Module-by-module inspection table |
| Upgrade Priority Plan | Decide which parts should be improved first |

## How to Use

1. Open the module audit table.
2. Pick one module at a time.
3. Check each page against the teaching quality criteria.
4. Mark the page as Ready / Minor Revision / Major Revision.
5. Use the priority plan to decide what to improve first.

::: tip Recommended Workflow
Do not try to rewrite the whole website at once. First identify weak pages, then upgrade the highest-priority pages one by one.
:::

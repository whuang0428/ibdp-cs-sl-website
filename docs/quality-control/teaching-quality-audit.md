# Teaching Quality Audit

## 1. Purpose

This checklist is used to judge whether each page is suitable for real IBDP CS SL teaching.

A page should not only contain information. It should help the teacher teach and help students learn, practise, and review.

---

## 2. Page Quality Levels

| Level | Meaning | Action |
|---|---|---|
| Ready | Can be used directly in class | Only small future polishing needed |
| Minor Revision | Mostly usable, but needs small improvement | Add missing examples, questions, or clearer explanation |
| Major Revision | Not ready for class | Rewrite or significantly expand |
| Hold | Not urgent or optional | Improve later if time allows |

---

## 3. Core Checklist for Every Teaching Page

Use this checklist for each content page.

| Area | Question | Rating |
|---|---|---|
| Lesson goals | Are the goals clear and specific? | ☐ Good ☐ OK ☐ Weak |
| Syllabus connection | Is the topic clearly connected to the course? | ☐ Good ☐ OK ☐ Weak |
| Key terms | Are key terms included with clear meaning? | ☐ Good ☐ OK ☐ Weak |
| Chinese explanation | Is the Chinese explanation clear for students? | ☐ Good ☐ OK ☐ Weak |
| English explanation | Is the English explanation usable for exam-style wording? | ☐ Good ☐ OK ☐ Weak |
| Example | Is there a realistic example? | ☐ Good ☐ OK ☐ Weak |
| Process / trace | Is there a step-by-step process, trace, or diagram-style explanation? | ☐ Good ☐ OK ☐ Weak |
| Code / pseudocode | If suitable, does the page include IB pseudocode or Java? | ☐ Good ☐ OK ☐ Weak ☐ Not needed |
| Common mistakes | Are common mistakes specific and useful? | ☐ Good ☐ OK ☐ Weak |
| Guided practice | Are there questions with hidden answers? | ☐ Good ☐ OK ☐ Weak |
| Independent practice | Are there enough questions for students to try? | ☐ Good ☐ OK ☐ Weak |
| Exam-style question | Is there at least one mark-scheme-style question? | ☐ Good ☐ OK ☐ Weak |
| Homework | Is homework practical and connected to the lesson? | ☐ Good ☐ OK ☐ Weak |
| Revision summary | Does the page end with a useful summary? | ☐ Good ☐ OK ☐ Weak |
| Classroom usability | Can a teacher use this page as lesson structure? | ☐ Good ☐ OK ☐ Weak |
| Student self-study | Can a student understand it without teacher explanation? | ☐ Good ☐ OK ☐ Weak |

## 6. Upgrade Priority Rules

Use these rules to decide what to improve first.

| Priority | Situation | Example |
|---|---|---|
| P1 | Core topic + weak explanation or weak practice | Loops, arrays, OOP classes, SQL SELECT, packet switching |
| P2 | Core topic + explanation okay but needs more exam questions | CPU, DNS, relationships, ML evaluation |
| P3 | Extension topic + useful but not urgent | Recursion, linked lists, social engineering |
| P4 | Support page or glossary polishing | command terms, checklist pages |

# Upgrade Priority Plan

## 1. Purpose

After the teaching quality audit, use this page to decide what to improve first.

The website is already complete as v1.0. The next stage should be **v1.1 quality upgrade**, not random rewriting.

---

## 2. Priority Levels

| Priority | Meaning | Recommended Action |
|---|---|---|
| P1 | Core learning risk | Improve before teaching this unit |
| P2 | Important but usable | Improve during normal preparation |
| P3 | Nice to improve | Upgrade when time allows |
| P4 | Low urgency | Leave for later |

---

---

## 4. v1.1 Upgrade Types

| Upgrade Type | What to Add |
|---|---|
| More examples | Add one extra classroom example and one real-world example |
| More code | Add Java + IB pseudocode pair |
| More tracing | Add trace table and “predict the output” questions |
| More exam practice | Add 3 short questions and 1 longer scenario question |
| Better hidden answers | Add mark scheme-style answers |
| Better bilingual support | Make Chinese explanation clearer and English exam phrases stronger |
| Static diagram | Add text-based or image-based process diagram |

---

## 5. Recommended First v1.1 Batch

Start with this batch:

```text
Batch 1: Programming Core
1. B2 Loops
2. B2 Arrays
3. B2 Searching
4. B2 Sorting
5. B3 Classes and Objects
6. B3 Encapsulation
```

Why:

- These pages affect student coding ability directly.
- They are harder for weaker students.
- They benefit most from extra Java code, trace tables, and practice tasks.

---

## 6. Second v1.1 Batch

```text
Batch 2: Exam Process Topics
1. A1 Fetch-Decode-Execute
2. A2 Packet Switching
3. A2 DNS and Web Access
4. A3 Primary and Foreign Keys
5. A3 SQL SELECT
6. A4 Model Evaluation
```

Why:

- They need exact process order and mark scheme vocabulary.

---

## 7. Upgrade Template for Each Page

When upgrading one page, add:

```text
1. One stronger real-world scenario
2. One worked example
3. One trace/process table
4. Three guided questions
5. Three independent questions
6. One 6-mark exam-style question
7. Hidden mark scheme answer
8. One common mistakes table update
```

For programming pages, also add:

```text
1. IB pseudocode
2. Java implementation
3. line-by-line explanation
4. predict-the-output task
5. modify-the-code task
```

---

## 8. Do Not Do Yet

Avoid these until v1.1 content quality is stable:

- complex animations
- backend/database features
- login system
- student progress tracking
- large interactive quizzes
- too many plugins
- over-styling before teaching quality is improved

The website should remain static, simple, fast, and easy to maintain.

# Start Here

## What is this website?

This is a static course website for IBDP Computer Science SL.

It is used for:

- lesson explanation
- student self-study
- revision
- programming practice
- exam-style preparation

## Content Labels

| Label | Meaning |
|---|---|
| SL Core | Required content for IBDP CS SL |
| HL Extension | Extra programming content from HL |
| School Extension | Extra content taught by our school |
| Exam Warning | Common exam mistake or important mark scheme idea |

## How to study

For each topic, students should follow this order:

1. Read the concept explanation.
2. Learn the key terms.
3. Study the worked example.
4. Try the quick check.
5. Practise the exam-style question.
6. Review the mark scheme style answer.
